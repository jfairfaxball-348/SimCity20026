## Defects corrected during verification

- Sidebar/help controls clipped at 720p: compact labels, bounded spacing, wider large-text sidebar, and layout assertions now cover the supported prototype sizes.
- Logical-only accessibility keyboard events initially failed: actions now include logical and physical bindings; tested in the native EXE.
- Very short pan taps could fall between frames: event-based tap movement complements held polling. Exact action matching prevents Ctrl+S from moving the camera.
- Preview text stayed at “release to build” after a stroke: cancellation/commit now refreshes it.
- Negative cell picking rounded incorrectly: floor is applied after division by cell size.
- A per-frame clock clamp lost time on long stalls: a 90-second partition regression now passes; the explicit one-hour total backlog bound remains.
- A narrow, tall seeded-map helper could let the shoreline exceed its width: generation is clamped, with a regression check.
- Exporting while an older test process still existed left an engine temporary EXE copy. Packaging refused the unexpected manifest entry; export metadata and ZIP creation now use explicit payload lists, excluding temporary/stale files. The old process was subsequently closed.
