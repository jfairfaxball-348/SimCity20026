## Decision before code

[R5_SPEC.md](../R5_SPEC.md) and D41 were written and adopted before code: full gamepad play with our own layout, a Menu reaching every dialog and command, dialog focus, plain-word prompts, a Controls dialog to remap keys and buttons, and settings version 3.

**Revisions during implementation, before delivery** (all found by the packed checks or the native run):

- Godot's `ui_accept`, `ui_cancel` and focus-movement actions did not include the gamepad in this project, so a focused button ignored South. The bindings now add South, East, the d-pad and the left stick to them, once.
- The same Back press opened the Menu and then closed it again; opening and closing are now exclusive.
- Embedded dialogs take their own input, so a waiting Controls row reads keys and buttons through the dialog's `window_input`; Escape there cancels the wait instead of closing Controls.
- The right stick pans through the same pan actions, read as analog because the keyboard check is exact-matched.
- Controls rows use their **Key** and **Pad** buttons to start a change (no separate Change button); the note says so.
- Center view, Sound & motion and Controls share one row in Display so it fits 720p.
- East did not close an open dialog (the dialog takes its own input); each dialog now closes on East from its own input (and the Menu on Back), except while a Controls row is waiting.
- A new "3 ObjectDB instances leaked" warning at the end of test runs came from effect playback with the headless dummy driver; effects now record the request but do not play in headless runs, and the director stops its players on exit.
