**Branch.** `codex/r3-autosave-history` from `416368c` (default branch `codex/m2a-road-access`, clean and matching origin after fetch).

## Decisions before code

- **U39.** ROADMAP R6 and its M3 placement table, and the DELIVERY_PLAN M3 gate, now name an owner solo playtest; R6 keeps its position after R1-R5. No consent note is needed.
- **D39.** [R3_SPEC.md](../R3_SPEC.md) and D39 were written and adopted before code: three rotating autosave slots every 60 days of running time that never touch the manual save; a versioned settings file with safe defaults; a 240-month history saved in schema 12 / `r3-1`; a Graphs dialog (H).

**Revisions during implementation, before delivery.**

- The first native run showed that Load went straight to the manual save when nothing was unsaved, so Load autosave could not be reached. With any autosave on disk the Load dialog now always opens ("Load your manual save, or the newest autosave?"). A packed check and a second native run cover it.
- An autosave happens after the frame that passes the 60-day mark; at 3x with several days per frame its date can be a few days after the boundary. The packed check accepts that window; the spec records it.

## Implementation

- **`city_state.gd`:** `history` (cleared on initialize, in the snapshot), schema 12 / `r3-1`.
- **`economy.gd`:** each settlement appends `[tick, residents, commercial jobs, industrial jobs, closing cash, net]` and keeps the latest 240.
- **`save_codec.gd`:** schema 12 with strict `valid_history()`; schema 11 accepted as an earlier format; earlier schemas reject `history`.
- **`save_store.gd`:** `save_autosave()`, `load_autosave()`, `has_autosave()`, slot paths, `autosave.index` rotation and fallbacks.
- **New `persistence/settings_store.gd`:** version-1 settings with exact keys and values, a 4 KiB cap, validated writes and an `override_path` for tests.
- **New `presentation/history_graph.gd`:** three original line graphs (solid and dashed lines, highest value and first/last month as text).
- **`main.gd`:** autosave after running frames that pass a 60-day mark; Load autosave in the Load dialog; settings applied at start-up and written on each player change (Display sizes and text, art, G, R, E, V, C, Hide/Close, F1, Help); First steps dismissal remembered; Town history dialog via H and Budget → Graphs [H]; Help.
- `docs/BUILD_README.txt`, `licenses/ASSETS.md`, version 0.16.0-r3.
